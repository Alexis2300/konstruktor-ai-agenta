# Конструктор AI-агента

Это локальный прототип лид-магнита. Он работает без регистрации, базы данных и подключения к AI-сервису. Ответы сохраняются только в браузере пользователя.

## Опубликованная версия

Сайт публикуется автоматически через GitHub Pages после изменений в ветке `main`.

Адрес: https://alexis2300.github.io/konstruktor-ai-agenta/

## Как посмотреть

1. Откройте PowerShell в этой папке.
2. Выполните команду:

```powershell
node preview-server.mjs
```

3. Откройте в браузере адрес:

```text
http://127.0.0.1:4173/
```

4. Чтобы остановить просмотр, вернитесь в PowerShell и нажмите `Ctrl+C`.

## Что уже работает

- шесть ролей и шесть шагов настройки;
- подсказки и понятные ошибки рядом с обязательными полями;
- сохранение незавершённых ответов в браузере;
- отдельный результат для Codex, Claude Code и обычного AI-чата;
- копирование и скачивание инструкции;
- консультация в Telegram для всех ролей;
- предложение внешнего сервиса только для роли «Нейропродавец»;
- мобильная версия.

## Важно

Это первая версия для просмотра и обсуждения. Она создаёт стартовую инструкцию агента, но не запускает настоящую автоматизацию, CRM или рассылку. Размещение на сайте и автоматическая выдача по кодовому слову будут отдельным следующим этапом после утверждения прототипа.
